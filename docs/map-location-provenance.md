# UK campus map location provenance

Pins are public university reference points, not verified KOC meeting rooms. They are never displaced to avoid overlap. The map uses a shared spherical Mercator projection for both the Natural Earth 1:50m UK outline and markers. Boundary: https://www.naturalearthdata.com/downloads/50m-cultural-vectors/50m-admin-0-countries-2/ (public domain). This includes mainland Scotland, Northern Ireland and Scottish islands.

The 24 previously verified points remain from `scripts/campus-locations.json`. The following 24 complete the named universities. Address/site choices were checked against university pages; coordinates come from OpenStreetMap/Nominatim (ODbL). Where a building match could not be verified, the official address postcode reference point is explicit. Multi-campus institutions use the documented site below; this does not establish which site hosts KOC. **Colleges** is a generic group without an institution/address and has no invented pin.

## Audit of earlier reference points

The earlier CCCU geocoder result pointed south of the documented North Holmes Road main campus. The corrective update uses the official campus address, CT1 1QU, explicitly as a postcode reference point. Wolverhampton previously used a Springfield-labelled university object; the corrective point is the verified Wulfruna Building at the documented City Campus. Both updates require exact original migration coordinates/source URL and empty meeting details, preserving administrator corrections.

Exeter Streatham Court is a documented teaching building on Streatham Campus; BCU Belmont Row is part of City Centre Campus; Bournemouth is Talbot Campus; Northampton is Waterside. The remaining prior points identify valid named university campus/building reference locations. These checks establish geographic university reference locations, not private KOC meeting venues.
